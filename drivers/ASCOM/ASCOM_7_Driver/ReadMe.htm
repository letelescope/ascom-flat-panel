ASCOM CoverCalibrator Driver installed

Thank you for installing the ASCOM CoverCalibrator Driver for Le Telescope FFFP.

Quick checks

  • Open the ASCOM Profile Explorer and confirm the driver is listed as ASCOM CoverCalibrator Driver for Le Telescope FFFP.
  • Use the ASCOM Diagnostics tools to open the driver, review its properties and Connect.
  • If needed, check logs in %USERPROFILE%\Documents\ASCOM\Logs.

Notes

  • The installer is unsigned. Windows may show a warning about an unknown publisher — this is expected for community builds.
  • For firmware, electronics and full project documentation visit: https://github.com/letelescope/ascom-flat-panel

If you have any problems, open an issue on the project GitHub
